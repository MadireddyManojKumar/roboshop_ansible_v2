# roboshop_ansible_v2
Ansible scripts to deploy roboshop microservices in AWS environment.

## Project Objectives

[ansible_roboshop](https://github.com/MadireddyManojKumar/ansible_roboshop/tree/master/roboshop_v1) was developed to streamline RoboShop deployments through Ansible automation.

`roboshop_ansible_v2` extends this foundation with an emphasis on deployment security and maintainability. Its key objectives are:

- **Secure secrets management:** Store keys and credentials in Ansible Vault and a dedicated secret store rather than in plain text.
- **Reduced boilerplate:** Consolidate repetitive logic into reusable components.
- **Improved project organization:** Adopt a clear, consistent structure that simplifies navigation and long-term maintenance.
